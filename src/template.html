사용법 · 단축키

시작

  • 이미지를 화면에 끌어놓거나 Ctrl+V로 붙여넣으세요. 텍스트는 위쪽 '텍스트' 탭에서 입력합니다.
  • 위쪽 '목적'에서 키링·레이저 등을 고르면 필요한 설정과 저장 버튼(노란 테두리)이 맞춰집니다.

화면 조작

  • 2D: 휠 확대 · 끌어서 이동 · 더블클릭 또는 H 처음으로
  • 3D: 끌어서 회전 · 오른쪽 끌기 이동 · 휠 확대 · 큐브의 면과 꼭지점 점을 누르면 그 방향에서 봄
  • D 치수 보이기·숨기기 · 치수 숫자를 누르면 바로 고침

편집

  • Ctrl+Z 실행 취소 · Ctrl+Y 다시 실행 (설정값 기준, 이미지 교체는 제외)
  • 텍스트 탭: 글자를 눌러 끌면 옮겨지고 방향키로 미세 이동(Shift는 크게)
  • 3D: 키링 고리는 끌어서 옮길 수 있음
  • 색 칸을 누르면 16 · 32 · 64 · 128색 색판이 열립니다 (맨 위에 지금 그림에 쓰인 색)

어떤 저장 버튼?

  • MakerLab 업로드 → SVG · MakerLab / 레이저 가공 → DXF · 레이저 (RDWorks) 또는 SVG · 레이저 (LightBurn)
  • 3D 프린트 → 3MF(색·받침판·고리가 각각 파트) 또는 STL(한 덩어리)
