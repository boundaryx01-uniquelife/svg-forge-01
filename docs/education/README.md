# 교육자료

SVG Forge로 만든 수업·연수 자료입니다. 대상에 따라 세 폴더로 나뉩니다.

| 폴더 | 대상 | 무엇을 배우나 | 분량 |
|---|---|---|---|
| [1-프로그램-사용법](1-프로그램-사용법/) | 누구나 | SVG Forge 전체 기능 (모드·편집·키링·레이저) | 20장 |
| [2-학생수업-나만의-키캡](2-학생수업-나만의-키캡/) | 초·중학생 | 그림과 글자를 MX 키캡으로 만들기 | 33장 |
| [3-교사연수-AI로-도구-만들기](3-교사연수-AI로-도구-만들기/) | 교사·강사 | 코딩 없이 수업 도구를 직접 만드는 방법 | 27장 + 핸드북 |

## 어떤 자료를 쓸까

- **학생과 만들기 수업을 한다** → 2번. 프로그램 조작이 처음이면 1번을 먼저 훑어보세요.
- **동료 교사에게 AI 활용을 설명한다** → 3번. 이 저장소를 만든 과정이 그대로 사례입니다.
- **프로그램 기능만 빠르게 확인한다** → 1번.

모든 PPT에 발표자 노트가 들어 있습니다. 화면 캡처는 실제 프로그램 화면입니다.

## 프로그램 파일

수업에 쓸 SVG Forge 본체는 저장소 `dist/` 에 있습니다.

| 파일 | 용도 |
|---|---|
| `dist/svg-forge.html` | 수업·개인 사용 (Potrace 포함, 외곽선 추적 품질 우수 · GPL) |
| `dist/svg-forge-nogpl.html` | 웹 배포용 — `index.html`로 이름 바꿔 올림 |

설치가 필요 없고 인터넷 없이 동작합니다. 학생 배포는 USB로 `svg-forge.html` 하나만 나눠 주면 됩니다.
