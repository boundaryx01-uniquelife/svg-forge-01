# 프로그램 사용법

| 파일 | 내용 |
|---|---|
| [SVG-Forge-사용법.pptx](SVG-Forge-사용법.pptx) | 20장 · SVG Forge 전체 기능 (발표자 노트 포함) |

다루는 내용

- **모드** — 자유 · 키링/네임택 · 키캡(MX) · 일반 3D · 레이저 가공
- **입력** — 이미지 불러오기, 글자 입력, 색 수·배경 제거
- **2D 편집** — 선택, 삭제, 구멍 채우기, 두께 ±, 끊기(✂), 같은 색으로(💧), 채우기(🪣), 글자 넣기
- **3D 출력** — 받침판, 테두리 턱, 키링 고리, 색상별 높이, 모따기·모깎기
- **레이저** — 절단 폭 보정, 색상별 작업 지정, 작업 미리보기
- **저장** — SVG · DXF · STL · 3MF · 프로젝트(.svgforge)

실제 수업에 적용한 예는 [2-학생수업-나만의-키캡](../2-학생수업-나만의-키캡/)을 보세요.
